# Port Fatigue Dashboard

基于黎曼流形与跨被试校准的码头作业人员疲劳度检测前端原型。

该项目用于演示港口远程操控场景中的疲劳风险监测界面，目前采用仿真数据，不连接真实 EEG 设备或生产业务系统。

## 页面功能

- 码头岸桥、集装箱与 AGV 仿真实时监控画面
- 疲劳风险分数及分级预警
- 注意稳定度、黎曼距离和风险持续时间联动显示
- 黎曼流形证据边界、预警域和高风险域可视化
- 每 2 秒更新一次仿真状态
- 适配桌面大屏与移动端布局

## 本地运行

项目不依赖构建工具，可直接打开：

```text
dist/index.html
```

也可以在项目目录启动静态服务器：

```bash
python -m http.server 8000 --directory dist
```

随后访问 `http://localhost:8000`。

## 项目结构

```text
dist/
├── index.html    # 页面结构
├── styles.css    # 科技化大屏样式与响应式布局
└── app.js        # 码头画面绘制及风险数据仿真
```

## 说明

界面中的风险边界、阈值和人员状态均为仿真数据，只用于原型展示和方法验证，不能直接作为实际安全决策依据。
