# 双子座头环实时接口

在项目根目录安装依赖并启动：

```powershell
python -m pip install -r interface/requirements.txt
python interface/sichiray_bridge.py --port COM8 --http-port 8766
```

打开 http://127.0.0.1:8766/ ，关闭仿真，接口地址使用 `./api/eeg/latest`。先关闭厂家软件的串口；两个程序不能同时读取 COM8。

已实测 COM8 / 115200：每行以换行符结束，21 个逗号分隔字段。第 5、6 列为 Fp1、Fp2 原始 ADC，按16位补码解释；第7、8列保留为设备滤波值。没有电压转换系数，界面单位为 ADC 计数。硬件采样率按提供规格为250 Hz，实测串口收包率随状态变化（本次观察约16–49包/秒），页面显示最近5秒实测速率，不能把每行当作完整250 Hz连续采样，更不能据此直接做频谱或原模型推理。

页面每250毫秒读取最新样本；后台持续接收每行数据。接口是最新快照，不是无损波形下载或录制接口。断流2秒判定无数据，串口错误自动重连。启动时可能收到半行并丢弃，parse_errors记录格式错误数量。

佩戴码0根据截图标记失败，其余码默认待确认。确认厂家正常佩戴码后可用 `--wear-ok-code 1`（仅示例）启用对应正常状态。设备专注度与放松度以设备原值显示；未确认正常佩戴时不进入专注度指标卡。设备指标不是疲劳概率。两通道不调用八通道模型，不生成全脑插值热图。

测试：`python -m unittest discover -s interface -p "test_*.py"` 和 `node interface/test_frontend.cjs`。


## 实时曲线
前端新增滤波后Fp1/Fp2、注意力和放松度曲线，可选择10/30/60秒窗口。`GET /api/eeg/samples?after=收包ID` 返回连续缓存、游标和会话标识；缓存最多15000包，重开串口时更换会话并清空历史。横轴使用实际接收时间，断流与缺包处断线，佩戴码0区段标红。设备滤波值直接取第7、8列，单位仍待核实；没有追加软件滤波或插值补造样本。关闭串口保留旧曲线直至滚出时间窗口。
